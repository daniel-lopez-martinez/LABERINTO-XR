# LABERINTO XR

**LABERINTO XR** is an independent, experimental and currently non-commercial XR project created by **Daniel Lopez Martinez** in Granada, Spain. It explores interactive narratives in which physical space and digital content both participate in the experience. The [official website](https://laberintoxr.io) is the canonical source for the project. Its domain uses the unspaced form LABERINTOXR for the same project.

## First experimental case: HEX001 — EL DESPERTAR

HEX001 is the first experimental experience within LABERINTO XR. It explores site-specific XR narrative design: the relationship between narrative actions, physical place, spatial registration and tolerance to spatial error. A [virtual experience](https://laberintoxr.io/mi-laberinto) is accessible on the official site; the on-site AR version remains in development. See the [HEX001 page](https://laberintoxr.io/hex/HEX001) for its current public description.

## Independent research in development

The current research question asks whether a site-specific narrative action can retain its dramatic function with lower geometric precision, and how its robustness changes as spatial error increases. **Spatial Coupling** and **Narrative Error Budgeting** are working concepts being developed around this question. **Two-Gate XR Acceptance** distinguishes technical validity from perceptual validity as a methodological principle.

The [living research protocol](https://laberintoxr.io/en/research/hex001-spatial-tolerance) describes proposed work. It is a protocol in development, with no experimental results or peer review claimed.

## Technical context

Development and documentation include Unity 6000.3.18f1 and OVER Unity SDK 0.5.0. These tools serve the narrative goal of using space as part of the storytelling language. A mention here does not claim a specific feature has been validated on a device. The [working technical overview](https://laberintoxr.io/technical-overview) distinguishes documented references, current project state and proposed validation.

## Repository scope

This is a **documentation repository**. It does not contain the full Unity project, a downloadable build, redistributable third-party assets or a dataset. No open-source or document reuse licence has been selected. Public visibility alone should not be taken as permission to reuse the materials.
